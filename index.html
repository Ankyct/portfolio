Projects

Watch Party - Screen Sharing Application

A web-based watch party application built with React, Node.js, Express, and LiveKit. It allows hosts to share screen and audio content with viewers through shareable rooms, with participant tracking, invitation links, and multiple streaming quality options.

League of Legends Champions Engine

An interactive JavaFX desktop application built with Java and Jsoup. It retrieves and displays League of Legends champion profiles, including background stories, images, and voice content, with JavaFX MediaPlayer for audio playback.

Audio File Converter

A Java application that converts OGG audio files into MP3 format using Java media libraries, file handling, I/O streams, and media encoding.

Worth It - AI-Powered Decision Companion

A team project developed during SteelHacks XIII using Next.js, React, TypeScript, NVIDIA Nemotron, and PostgreSQL. It helps users make decisions with AI-powered support. I contributed to frontend/UI development and helped integrate the NVIDIA Nemotron model.
